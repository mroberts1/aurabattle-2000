AURABATTLE 2000

Welcome to the plaza

Two battlers. One ring of judges. No rules. No mic. Just aura.

Pose. Hold. Clown. Stare Down. Farm. Clip Farm.

This is the first public prototype of AURABATTLE 2000, an open-source game inspired by real aura battles in Latin America. It is a single HTML file with no account, no install and no trackers.

Sound is on by default. Tap the Mute button once it starts.
